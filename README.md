# REST API in Crow C++

A simple rest API written in C++ via the CROW framework.

## Resources

1. The tutorial I am following: [Setting up a simple web server using Crow framework](https://www.youtube.com/watch?v=8aHg040HsLI)
2. Official documentation for Crow: [Crow: A Fast and Easy to use microframework for the web](https://crowcpp.org/master/) 

## Setup

This project requires a few external dependencies to function and compile.

### 1. Crow

Please download the latest build of [CROW (v1.3.1) from their official page](https://github.com/CrowCpp/Crow/releases/tag/v1.3.1).

- Download the `tar.gzip` file and extract to a directory inside the `src/include` directory.

### 2. Boost

Please download the latest version of the [BOOST (1.9.00) library from their official page](https://www.boost.org/releases/latest/)

- Download the `tar.gzip` file and extract to a directory inside the `src/include` directory.
